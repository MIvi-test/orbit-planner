# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Записи пишутся
для пользователя и администратора сервиса: что изменилось в поведении, данных,
запуске. Внутренняя кухня — в `FIXES_TRACKER.md` и ADR.

Каждый MR добавляет строку в раздел «Не выпущено» (правило —
`IMPLEMENTATION_PLAN.md` §2.3). Идентификаторы пунктов — из `FIXES_TRACKER.md`.

## [Не выпущено] — ветка `release/product`
