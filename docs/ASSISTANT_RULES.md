# Краткие правила KPI и сценариев

Источник этих правил — действующий [PLANNER_SPEC.md](PLANNER_SPEC.md) и код
планировщика текущей версии. Этот документ служит коротким указателем для
помощника; при расхождении приоритет у спецификации и сохранённого снимка.

## PI Predictability

Знаменатель — инициативы, целиком обещанные каноническим планом Недели 0.
Числитель — инициативы, завершённые в пределах PI. Если обещанных инициатив
нет, показатель не определён (`N/A`). Частично включённая инициатива не равна
целой обещанной инициативе.

## Say/Do Ratio

Знаменатель — SP, обещанные первоначальным планом на спринт. Числитель — SP,
подтверждённые фактом завершения в этом спринте события. Без обещанных SP
показатель `N/A`. Неполный отчёт спринта не создаёт фактический KPI.

## Bus Factor

Оценивается по навыкам, требуемым живым бэклогом. Для критичного навыка
используется число подтверждённых носителей. Если релевантных навыков нет,
показатель `N/A`. Не размеченное требование нельзя считать подтверждённой
компетенцией; приближение через роль должно быть явно названо приближением.

## Сценарные меры

Наём, обучение и перевод ставки — гипотезы, а не запись в рабочий план.
Влияние меры зависит от роли, команды, ставки, даты вступления в силу,
доступности людей и затрат наставника. Эффекты отдельных мер нельзя просто
сложить: совместный пакет требует отдельного расчёта на одном исходном снимке.
Если параметры меры не заданы, нужно запросить их; нельзя выдавать численный
эффект без расчёта.
